# HRM-03 — Talent Intelligence Platform

HRM-03 is a hackathon MVP that helps teams discover internal talent using employee skills, role requirements, project experience, and deterministic match explanations.

## Problem

Organizations can overlook skills and experience already present in their workforce, leading them to search externally while internal talent and project evidence remain difficult to discover.

## Solution

HRM-03 brings employee profiles, demonstrated skills, project contributions, and target roles into one lightweight platform. Recruiters can find candidates by role and skills, inspect match evidence, explore employee-skill-project-role relationships, and review practical upskilling paths and internal opportunities.

## Key Features

- Dashboard with live employee, availability, skill, project, and role metrics.
- Talent Search with deterministic matching, score factors, skill gaps, project evidence, and candidate profiles.
- Skill Graph connecting employees, demonstrated skills, projects, and compatible roles.
- Upskilling paths with proficiency-aware gaps, learning steps, and estimated compatibility.
- Internal Marketplace with demo projects, roles, courses, and mentorship opportunities.
- Responsive interface and seeded demo data; no authentication or external AI service required.

## Technology Stack

- Frontend: React, Vite, Tailwind CSS, React Router, Axios, Lucide React, Recharts.
- Backend: Python, FastAPI, SQLAlchemy, SQLite, NetworkX.
- Matching and explanations: deterministic rules over employee, skill, project, and role data.


## Requirements

- Node.js 20.19+ or 22.12+.
- Python 3.10+.

## Database Setup

The app uses one SQLite database, `hrm03.db`, in the project root. `backend/seed.py` creates the schema and inserts 10 employees, 12 skills, 5 roles, 6 projects, and their skill/project relationships. It is safe to rerun without duplicating records.

The database file is local and ignored by Git. Recreate it from the included seed script when setting up a fresh checkout.

## Run the Backend

From the project root in PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
Set-Location backend
python seed.py
python -m uvicorn app.main:app --reload
```

The API runs at `http://127.0.0.1:8000`. Interactive documentation is available at `http://127.0.0.1:8000/docs`.

### Nova Invoice Proxy

Copy `backend/.env.example` to `backend/.env`, then set `NOVA_API_KEY` to your rotated Nova API key. The base URL is configured in the example. The local `.env` is ignored by Git.

With the backend running, test the proxy at `http://127.0.0.1:8000/api/nova/invoices`. It requests up to five invoices from Nova. Do not put the key in frontend code, commit it, or include it in screenshots or logs.

## Run the Frontend

In a second terminal from the project root:

```powershell
Set-Location frontend
npm install
npm run dev
```

Open the URL printed by Vite (normally `http://localhost:5173`). Vite proxies `/api` requests to the backend.

## API Overview

- `GET /api/health` — service status.
- `GET /api/employees` — employee profiles with skills and project contributions.
- `GET /api/skills` — skill catalog.
- `GET /api/roles` — target roles and required skills.
- `GET /api/projects` — projects and employee contributions.
- `POST /api/talent/search` — ranked candidates with match factors and evidence.

Talent Search uses skills (50%), proficiency (20%), experience (15%), and relevant projects (15%). Upskilling and Marketplace use existing APIs plus deterministic frontend demo data; no extra endpoints are required.

## Demo Flow

1. Open the Dashboard and review live workforce metrics.
2. Search for AI Engineer with Python and Machine Learning in Talent Search.
3. Open “Why this candidate?” to inspect score factors, proficiency, gaps, projects, and experience evidence.
4. Explore employee skills, projects, and related roles in Skill Graph.
5. Select an employee and target role in Upskilling to review gaps and a learning path.
6. Search/filter internal opportunities and open details in Marketplace.
